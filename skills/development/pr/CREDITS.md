# 致谢

**概要**一节的可视化选项（伪代码、调用树、组件树、文件树、Mermaid、diff）及其摆放原则，来自 [Dex Horthy](https://github.com/dexhorthy) 的 [`show-me`](https://github.com/humanlayer/humanlayer) skill。上游 [mattpocock/skills](https://github.com/mattpocock/skills) 的 `pr` 几乎逐字收录了这部分内容，并把对象从实时对话换成了 diff；本仓库的 `pr` 由上游版本翻译改写而来。

`pr` 不把 `show-me` 作为依赖 skill 引用：它不在本仓库中，硬依赖会让单独安装失效。因此内容直接复制进来，本文件代替依赖本应承载的署名。
