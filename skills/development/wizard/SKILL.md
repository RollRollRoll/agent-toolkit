# Wizard

**向导（wizard）**是一个 bash 脚本，它**一步一步**带着人走完一套手工流程——
那种手动做很烦、每次还要重新讲给 AI 听一遍更烦的流程。它替你打开每一个 URL，
**准确说出该点什么、该复制什么**，把值捕获下来，**写到它们该去的地方**（`.env`、GitHub secret），
**每一阶段都确认**，并且**告诉你还剩几个阶段**。它可能是去配置第三方服务、跑一次性迁移，
也可能是把项目从一个状态挪到另一个状态。

**那套讨人喜欢的 UX 已经被 [scripts/template.sh](scripts/template.sh) 解决掉了**：
逐阶段的进度、确认闸门、跨平台打开 URL（含 WSL）、隐藏输入的密钥、幂等的 `.env` upsert、
`gh secret` / `gh variable` 写入，以及收尾的总结。
**你的活只有一件：把流程的范围定下来，并把它的各个阶段写出来。**
`STAGES` 标记以上的那段库**在每个向导里都是一模一样的**；
**这份一致性正是重点：绝不要手改它。**

**向导默认是一次性的**：为一次运行而造，存到 scratch 或 `scripts/` 下的某个路径，活干完就删掉。
**只有当用户要的是一条该住在仓库里、可重复的配置路径时，才提交它。**

## 流程

### 1. 把流程的范围定下来

把人**必须**手动做的每一步、以及沿途会捕获到的每一个值都摸清楚。**先读仓库，别空口问**：

- **配置类**：`.env`、`.env.example`、`.env.*`、`README`、`docker-compose*`、框架配置，
  以及 `.github/workflows/*`（**每一处 `secrets.*` / `vars.*` 引用都是这个向导必须产出的值**）。
- **迁移或切换类**：当前状态、目标状态，以及两者之间那些**不可逆**的动作。

然后**把有序的阶段清单、以及每个阶段产出的值摆给用户看，并确认**：他可以加、可以删、可以调顺序。

**完成判据**：每个阶段都按顺序命名了；并且对每一个被捕获的值，你都知道
(a) **人从哪儿拿到它**，(b) **它被写到哪儿**（`.env`、GitHub secret、两者都写，还是哪儿都不写——
**有些阶段就是纯动作**），(c) **它是不是密钥**（要不要隐藏输入）。

### 2. 把每个阶段的路径画出来

对每个阶段，写下**人要走的那条精确路径**：打开哪个 URL、在那儿做什么、值显示在哪儿、
它填进哪个变量——比如「Dashboard → Developers → API keys → Reveal test key → 复制」。
**凡是你并不真的知道当前 UI 长什么样、或者不知道确切命令的地方，就明说出来**，
去问用户或者查文档：**绝不要编出可能根本不存在的步骤。**

**完成判据**：每个阶段都能落到**一个陌生人照着就能走**的具体指令上。

### 3. 把向导写出来

把 `scripts/template.sh` 复制到目标路径。**把那个示例阶段替换掉**，
按依赖顺序**一步一个 `stage`**。用库里的 helper：`stage`、`say`/`step`、`open_url`、
`ask`/`ask_secret`、`write_env`、`set_secret`/`set_var`、`pause`/`confirm`。
把 `TOTAL_STAGES` 设成你写的阶段数。

**守住模板定下的那条线**：**先打开 URL，再问它的值**；任何密钥都用 `ask_secret`；
每一个要留下来的值都 `write_env`；**只有 CI 真的需要的值才 `set_secret`**；
**任何不可逆的动作之前都 `confirm`**。**每个 `stage` 都会清屏**，屏幕上只剩当前这一步——
**所以一个阶段只放一件专注的事**，别让人正需要的东西滚出屏幕。**标记以上的库不要碰。**

### 4. 验证并交付

- `bash -n <script>`；有 `shellcheck` 就跑一下。
- `chmod +x <script>`。
- **不要自己端到端跑它**：它会打开浏览器，而且会卡在等人输入上。**改成静态地走一遍**：
  第 1 步里的每一个值都被捕获了、并且落到了第 1 步说的那个地方，
  而且**每一个 `set_secret` 的名字都与 CI 里某处 `secrets.*` 引用完全对得上**。
- **告诉用户怎么跑它。** 如果它是一条可重复的配置路径，**提交它，并从 README 链过去**，
  好让下一个人**去跑这个脚本，而不是再问一次 AI**。
