name: research
description: 针对一个问题查阅高可信一手来源，把结论写成仓库里的 Markdown 文件。用于用户要求调研某个主题、收集文档或 API 事实，或希望把查阅资料的活派给后台 agent。
---

派一个**后台 agent** 去做调研，这样它读资料的时候你可以继续干活。

它的任务：

1. 对着**一手来源**（官方文档、源码、规范、第一方 API）调研这个问题，而不是别人对它的转述。每条结论都追回到拥有这个事实的来源。
2. 把结论写进单个 Markdown 文件，逐条注明来源。
3. 存到仓库已经放这类笔记的地方，沿用既有约定；没有约定就放一个合理的位置，并说明放在哪。
