# Research

## 用途

把明确的技术问题委托给后台 agent，依据官方文档、规范、源码和第一方 API 等高可信一手来源完成调研，并将带逐项引用的结论写入仓库内单个 Markdown 文件。

## 触发场景

- “调研一下这个 API 的官方行为，并把结论写进仓库”
- “查清这个技术选型在官方文档和源码中的依据”
- “让后台 agent 阅读规范，整理成带引用的调研笔记”
- 不适用：完整代码库架构调研、只需口头回答的简单事实、代码评审或直接实现功能。

## 行为边界

- 一手来源优先；二手资料只用于发现线索。
- 每项关键结论都要有能直接支撑它的来源。
- 只写一个调研 Markdown 文件，不顺带修改代码或落实建议。
- 优先沿用仓库既有笔记位置；没有约定时使用简洁合理的路径并在交付时说明。

## 使用方式

将本目录复制到目标平台的 skill 目录（Claude Code：`.claude/skills/research/`；Codex：`.agents/skills/research/`）即可使用。

## 目录说明

- `SKILL.md`：skill 主体（平台原生格式，含 frontmatter）。
- `agents/openai.yaml`：Codex 的展示名称、简短描述和默认提示词。
